# NETWORK-TROUBLESHOOTING-ASSISTANT
# Network Troubleshooting Assistant

A Python-based network troubleshooting assistant that collects network evidence, analyzes connectivity failures, and provides evidence-based diagnostic guidance for IT support technicians.

## Project Status

🚧 Version 1 — In Development

## Purpose

The project aims to help IT support technicians troubleshoot network connectivity problems quickly by collecting relevant network information, testing connectivity, analyzing the evidence, and suggesting what to investigate next.

## Core Workflow

Destination → Evidence Collection → Analysis → Diagnosis → Recommended Action

## Version 1 Scope

- Network interface information
- IP configuration
- Subnet identification
- DNS resolution
- Default gateway
- Routing information
- Same-subnet determination
- Gateway reachability
- Destination reachability using ICMP
- Network path analysis
- Evidence-based diagnosis

## Safety

Version 1 is read-only. The tool does not modify network configuration, firewall rules, routes, interfaces, caches, or other system settings.

## Technology

- Python
- Operating-system networking utilities
- Git & GitHub

## Learning Context

This project is being developed as a practical bridge between networking fundamentals and Python programming, with future potential for automation, Linux, cloud networking, and cybersecurity applications.
